# TM Pizzaria Android

Projeto Android (WebView) para gerar APK de teste.

## Gerar APK
1. Abra este projeto no Android Studio, com SDK instalado.
2. Aguarde a sincronização Gradle.
3. Execute Build > Build APK(s).
4. APK debug: `app/build/outputs/apk/debug/app-debug.apk`.

Alternativa sem computador local: envie o conteúdo deste projeto para um repositório GitHub. Na aba Actions, execute o workflow **Build TM Pizzaria APK**; o APK será disponibilizado como artifact após a execução.
